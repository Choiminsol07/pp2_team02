### 파이썬 함수를 한곳에 모아 함수별 기능과 사용 방법, 예제를 쉽게 확인할 수 있도록 설정
### 개발 형태 : Python tkinter 기반 데스크톱 GUI 프로그램
### 주요 대상 : 파이썬을 처음 배우는 초급 학습자
### 핵심 기능: 함수 검색, 설명 및 예제 제공
#
# 팀원별 역할 분담
### 최민솔(팀장)	파이썬 함수 자료 정리, GitHub관리 , tkinter 화면 설계 및 구현 
### 조영채	JSON 및 데이터 관리 클래스 구현, 코드 구조 정리
### 박지연	함수 검색 및 카테고리 분류 기능 구현, PPT 제작
### 김윤빈	즐겨찾기 및 공식 문서 연결 구현, 발표 자료 취합 및 정리
#
# 주요 기능
### 1. GUI (tkinter)**
### : 검색창, 검색 버튼, 결과 목록, 상세 설명 화면, 즐겨찾기 화면 등을 구성한다.

### 2. 파일 입출력 (JSON)**
### 함수 정보와 사용자 즐겨찾기 데이터를 JSON # 파일로 저장하고 불러온다.

### 3. 객체지향 프로그래밍 (Class)**
### 데이터 관리, 검색, 사용자 기능, GUI 등 역할별로 클래스를 구성하여 프로그램을 #관리한다.

### 4. 자료구조 (list, dict, set)**
### - list: 검색 결과 목록 및 최근 검색 기록 관리
### - dict: 함수명, 설명, 카테고리, 예제 등 함수 정보 관리
### - set: 즐겨찾기 중복 등록 방지
